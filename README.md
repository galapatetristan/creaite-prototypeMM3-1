# CreAIte — Prototype Website (Static)

This is a simple, responsive landing page prototype based on your Marketing Management paper.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Run locally
Just open `index.html` in a browser.

## Deploy on GitHub Pages (free)
1. Create a GitHub repo (public is easiest).
2. Upload these 3 files to the repo root.
3. Go to **Settings → Pages**
4. Under **Build and deployment**, set:
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)`
5. Save — GitHub will give you a `https://<username>.github.io/<repo>/` link.

Tip: GitHub Pages is free. The only thing that costs money is a custom domain (optional).
